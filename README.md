## ✨ Features & Highlights

1. **Lightweight & Fast-Loading**: Zero heavy framework overhead, pure semantic HTML5, Vanilla CSS3, and JavaScript (<80 KB total footprint).
2. **Fully Responsive & Mobile-First**: Built with responsive grids and custom typography for mobile phones, tablets, and desktop displays.
3. **Live Store Status Badge**: Automatically computes whether the service center is open and accepts bookings based on Indian Standard Time (IST).
4. **Interactive Cost Estimator & Quote Calculator**: Select appliance and fault type for upfront price estimates and direct 1-click WhatsApp quote booking.
5. **Direct 1-Tap Booking**: Instant `tel:` calls and pre-formatted WhatsApp chat dispatches with address & issue details.
6. **Dark / Light Theme Toggle**: Seamless mode switching with persistent local storage preferences.
7. **Interactive Service Tabs & FAQ Accordion**: Smooth filtering and collapsible answers.
8. **SEO & Structured Data**: Complete Schema.org `LocalBusiness` JSON-LD markup, OpenGraph tags, and semantic structure.
9. **GitHub Pages Ready**: Self-contained `index.html`, `styles.css`, and `script.js` located in the root directory.

## 🚀 How to Host on GitHub Pages

1. Push this repository to GitHub:
   ```bash
   git add .
   git commit -m "Add Tech Care single page website"
   git push origin main
   ```
2. Navigate to your repository on GitHub.
3. Go to **Settings** > **Pages**.
4. Under **Branch**, select `main` (or `master`) and `/ (root)` folder.
5. Click **Save**. Your site will be published at `https://<username>.github.io/<repo-name>/`.
